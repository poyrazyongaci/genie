# Contributing

Bug reports with a transcript of what happened are the most useful thing you
can send. Remove private text first.

1. Open an issue for anything larger than a fix
2. Read `AGENTS.md` for the rules of this repo
3. Add a test that fails without your change
4. Run the four commands at the end of `AGENTS.md`
5. Add a line to `CHANGELOG.md` under Unreleased

## Good first changes

| Area | Wanted |
|---|---|
| labs | a job for tracks that only have an outside score |
| watcher | sessions on Windows, where `ps` is missing |
| second opinion | tested setups for programs other than Codex |
| field reports | your own run, with counts, good or bad |

By contributing you agree that your work is released under the MIT license.
